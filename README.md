# Rivals

Tools for Marvel Rivals chat customization.

## Packages

### [tui/](./tui/)
Terminal-based rainbow text converter. Create colorful chat messages with custom patterns and real-time preview.

### [webapp/](./webapp/)
Web application (coming soon).

## Quick Start

### TUI
```bash
cd tui
./src/rivals-tui-modular.zsh
```

## Requirements

**TUI:**
- `zsh` shell
- Clipboard utility (`xclip`, `pbcopy`, or `xsel`)
- `jq` (optional, for custom patterns)
