# Marvel Rivals Terminal Tools 🌈

## Rainbow Text Converter TUI

Convert any text to Marvel Rivals rainbow format with a beautiful, interactive interface.

### Quick Start

**Original TUI** (Simple & Fast):
```bash
./rivals-tui.zsh
```

**Enhanced TUI** (With Custom Pattern Creator):
```bash
./rivals-tui-enhanced.zsh
```

### Enhanced TUI Features

#### 🎨 Custom Pattern Creator
Create your own color patterns interactively:
- **Pattern Name** - Give your pattern a unique name
- **Icon Selection** - Choose from 12 icons to represent your pattern
- **Color Builder** - Select colors visually with live preview
- **Real-time Preview** - See how your pattern looks as you build it

#### 📚 Pattern Manager
Manage all your patterns in one place:
- **Browse Patterns** - Navigate through built-in and custom patterns
- **Edit Custom Patterns** - Modify your existing patterns
- **Delete Patterns** - Remove unwanted custom patterns
- **Quick Selection** - Jump directly to any pattern

#### 🚀 Enhanced Navigation
- **Tab/Shift+Tab** - Navigate patterns forward/backward
- **Visual Hints** - See previous/next pattern indicators
- **Pattern Counter** - Know your position (e.g., 3/15)
- **Custom Pattern Tags** - Easily identify your custom patterns

### How to Create a Custom Pattern

1. **Press Ctrl+P** in the main screen to open Pattern Manager
2. **Press 'N'** to create a new pattern
3. **Enter Pattern Details**:
   - Type a name for your pattern
   - Press Tab, select an icon with arrows, press Space to confirm
   - Press Tab, use arrows to navigate colors, Space to toggle
4. **Save Your Pattern** - Press 'S' when you're happy with the colors
5. **Use Your Pattern** - It's automatically selected and saved for future use!

### Controls

**Main Screen**:
- **Type** - Enter your text
- **Tab** - Next pattern
- **Shift+Tab** - Previous pattern
- **Enter** - Copy to clipboard
- **Ctrl+P** - Open Pattern Manager
- **Esc** - Quit

**Pattern Creator**:
- **Arrow Keys** - Navigate options
- **Space** - Select/Toggle
- **Tab** - Next step
- **S** - Save pattern
- **Esc** - Cancel

**Pattern Manager**:
- **↑/↓** - Browse patterns
- **Enter** - Select pattern
- **N** - New pattern
- **E** - Edit (custom only)
- **D** - Delete (custom only)
- **Esc** - Back to main

### Marvel Rivals Color Codes
The converter uses official Marvel Rivals color codes:
- **Y** = Gold
- **O** = Orange
- **R** = Red
- **P** = Pink
- **M** = Really Pink
- **U** = Purple
- **B** = Blue
- **I** = Dark Blue
- **A** = Teal
- **T** = Blue Green
- **G** = Green
- **E** = Green Yellow
- **K** = Yellow
