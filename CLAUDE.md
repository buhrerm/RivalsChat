# Marvel Rivals Terminal Tools 🌈

## Rainbow Text Converter TUI

Convert any text to Marvel Rivals rainbow format with a beautiful, simple interface.

### Usage
```bash
./rivals-tui.zsh
```

### Features
- **Live Preview** - See rainbow text as you type
- **3 Color Patterns**:
  - 🌈 Rainbow - Full 13-color spectrum
  - 🔥 Warm - Fire colors (Gold, Orange, Red, Pink)
  - ❄️ Cool - Ice colors (Purple, Blue, Teal, Green)
- **Simple Controls**:
  - Type text → See instant rainbow preview
  - Tab → Switch between patterns
  - Enter → Copy to clipboard
  - Esc → Quit

### Marvel Rivals Color Codes
The converter uses official Marvel Rivals color codes:
- **Y** = Gold
- **O** = Orange
- **R** = Red
- **P** = Pink
- **M** = Really Pink
- **U** = Purple
- **B** = Blue
- **I** = Dark Blue
- **A** = Teal
- **T** = Blue Green
- **G** = Green
- **E** = Green Yellow
- **K** = Yellow

### Quick Start
1. Run `./rivals-tui.zsh` to start the rainbow converter
2. Type your message
3. Press Tab to try different color patterns
4. Hit Enter to copy the rainbow code
5. Paste in Marvel Rivals chat!
